# Placeholder asset inventory

Generated by `tools/Nosum.AssetInventory` from the code and the maps; do not edit by hand. Regenerate with
`dotnet run --project tools/Nosum.AssetInventory` ([`tools/README.md`](../../tools/README.md)). The plan that uses it is
[ADR-040](../adr/ADR-040-own-art-plan.md); the content is the unpacked Stardew Valley files of `assets/` ([ADR-007](../adr/ADR-007-placeholder-content-16px.md)).

**Reading it.** A *cell* is one square of a file's grid (the *grid* column: 16 × 16 px tiles unless stated). A cell is *used* when the
code draws any pixel of it: a tile placed on a drawn layer of a hosted map, or a sprite rectangle a catalogue, a sprite table or a
drawing routine names. A *frame* is a used cell that belongs to a walk, direction, growth or animation sequence. A cell several
packages draw belongs to the first of them in priority order, so every cell is counted once. A file with 0 used cells is still
loaded (a map names it as a tileset) and must exist at its size. The *Art* column compares each file with the fingerprint recorded in
`placeholders.sha256`: `placeholder` while the file still has the placeholder's hash, `replaced` once it differs and keeps the recorded size.
