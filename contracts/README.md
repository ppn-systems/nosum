# contracts/

Types that cross the wire, shared byte-for-byte by the server and the browser client:
opcodes, Nalix packets, DTOs, enums and `NosumProtocol.Version`. **No logic.**

Layout: `Nosum.Contracts/{Domain}/{C2S,S2C}/` plus one `*OpCode` class per domain.
Rules for packet classes: [`nalix-packets`](../.claude/skills/nalix-packets/SKILL.md).

`NosumProtocol.Version` is 13; its doc comment lists every change since 8. At 9, Google and Microsoft sign-in replaced passwords (docs/adr/ADR-069). `ExternalSignIn` and `LinkExternalIdentity` are new; `Register`, `Login`, `UpgradeGuest`, `ChangePassword` and `PasswordResult` are retired and have no fields.

`NosumProtocol.Version` is 3: `JoinMapResult` gained `MapId` and `Facing` (ADR-012 D6, version 2); nicknames appended fields to `Register`, `UpgradeGuest`, `AccountResult`, `LookRow`, `ListingRow`, `CoopMemberRow` and `CoopInviteRow` (version 3, [ADR-009 amendments](../docs/adr/ADR-009-postgresql-persistence-and-accounts.md)). The Placeable band (and its `0xB100` slice, with `PlaceStatus` values 15-18) only adds packets and appended enum values, so it needs no bump by itself. The Visit band only adds packets and three appended status values (`FarmStatus.NotYourFarm`, `PlaceStatus.NotYourPlace`, `MarketStatus.NotYourBin`), so it needs no bump. The Node sub-range (`0x7100`) and ground items (`0x7200`) only add packets and enum values, so they need no bump either. The social layer only added packets in new bands too.
A place is a map instance (a shared map, or one player's private farm or farmhouse); none of that is on the wire: `FarmSnapshot.MapId`, `MapChanged.MapId` and `PlacedSnapshot.MapId` are map ids and the server knows whose copy the connection is in.

Shared enums that are not tied to one domain live in `Nosum.Contracts/Common` (`GameLanguage`,
with `GameLanguages` as its one mapping to BCP-47 tags).

dotnet build contracts/Nosum.Contracts.slnx
