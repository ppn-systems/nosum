# Assets pipeline

Decisions: `docs/adr/ADR-007-placeholder-content-16px.md` (current), ADR-004/005/006 as amended.

## Non-negotiables

- **`assets/` holds only Nosum's own or CC0 replacement sprite sheets**, at the paths the code loads,
  listed in `docs/art/inventory.md`. The Stardew Valley placeholder content is gone from the tree
  (ADR-040 phase 4): never restore it, copy it into another repository or present it as Nosum's art.
  It is in git history only. Code must not depend on anything that cannot be re-created by Nosum's
  own art later (keep conventions, not content).
- **16 × 16 px tiles**, drawn at a whole-number scale with `imageSmoothingEnabled = false`.
- **Sheets are used as shipped** — address frames by sheet + grid index; do not repack them.
  `tools/Nosum.AtlasPacker` is for Nosum's own art only (`--assets <dir>`), not for `assets/`.
- **Maps are Tiled `.tmx`.** Tile layers map to ADR-005 layers: `Back` → ground,
  `Buildings` → world (depth-sorted objects), `Front`/`AlwaysFront` → front.
- **Player characters are layered** (`assets/Characters/Farmer/`): base, pants, shirts,
  hairstyles, hats, accessories on 16 × 32 frames, composed once per appearance change (ADR-006).
- **Own maps and their tilesheets live in `art/own/`.** A re-authored map is generated by `tools/Nosum.MapReauthor` and linked to the path the game loads (`art/README.md`); regenerate it with the tool, never edit it by hand. The sprite sheets in `assets/` sit at their own paths and are listed in `docs/art/inventory.md`.
- **Do not edit files in `assets/`.** Derived data goes elsewhere (e.g. a generated index under
  `wasm/`), so the folder can be swapped wholesale when the remake lands.
- **Adding or changing what the game loads from `assets/`** (a map, sheet, sprite-table entry, catalogue sheet) means regenerating
  `docs/art/inventory.md` (`dotnet run --project tools/Nosum.AssetInventory`); `AssetInventoryTests` fails otherwise. Plan: ADR-040.
